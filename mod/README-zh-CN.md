# DD2 Skill Controller — 使用指南

适用于 PC Steam 版《Dragon's Dogma 2》的 REFramework Lua Mod，管理觉醒者和主随从的武器主动技能、职业资格、职业等级与 JP。

## 环境与安装

预先安装 [REFramework](https://github.com/praydog/REFramework)。修改存档前退出游戏，备份 Steam `userdata/<Steam 数字 ID>/2054970/` 完整目录。

**手动安装**：将安装 ZIP 的 `reframework` 文件夹合并到游戏根目录，与 `DD2.exe` 同级，保持以下结构：

```text
reframework/
  autorun/
    DD2SkillStateManager.lua
    DD2SkillStateManager/
      access.lua
      catalog.lua
      diagnostics.lua
      i18n.lua
      operations.lua
      progress.lua
      progress_access.lua
      ui.lua
  fonts/
    DD2SkillStateManager-CJK.otf
    DD2SkillStateManager-CJK-LICENSE.txt
```

**Fluffy Mod Manager**：选择 Dragon's Dogma 2，导入安装 ZIP 并启用。包内提供 `modinfo.ini`。请导入安装包而非源码包；包结构已检查，管理器具体安装行为需人工验证。

游玩无需 Python 或其他 Lua 库。

## 技能管理

1. 进入存档，按 Insert，在 **Script Generated UI** 展开 **DD2 技能与职业管理**。
2. 选择“技能”页面，选择职业和技能，可按名称或 ID 搜索。
3. 查看当前获取状态，选择有效的目标等级。
4. 点击“学习 / 设置等级”或“删除技能”，检查预览，再点绿色“确认修改”。
5. 如技能被自动卸下，在游戏中重新装备，再按正常方式保存。

普通职业技能同步修改双方，觉醒者专属职业仅修改觉醒者。必要角色不可访问时取消整个操作。每项技能只提供已核验的实际等级，单级技能只有一个已获取等级；获取状态与原始等级分开管理。

删除或实际等级变更会自动清空所有相关技能槽，包括其他职业的保存配置和龙选者引用，具体位置在预览列出。已获取且同级属于无操作，保留装备；已清空的槽位不会自动重新装备。

“批量学习”提供当前职业与全部职业两个范围，每项取自身最高可用等级，名称搜索不影响范围。若存档已有更高原始等级，该同步技能整体跳过；需要主动降级时使用单项设置。无法核验或内容不可用的项目会列出跳过原因。

## 职业与 JP

选择“职业与 JP”页面。“当前状态”只读显示双方正在使用的职业、等级和 JP。

在“编辑所选职业”选择觉醒者、主随从或双方，再选择职业，默认角色为觉醒者。此区对比该职业在双方的资格和等级，并提供编辑按钮。

| 操作 | 行为 |
| --- | --- |
| 解锁职业 | 仅给予资格，保留首次转职记录、等级、JP、技能与装备；首次转职仍按游戏正常规则收费。 |
| 锁定职业 | 清除资格，保留进度和装备配置；需先转离正在使用的职业，基础职业不可锁定。 |
| 设置职业等级 | 使用游戏有效等级范围及对应累计职业经验；同级设置保留经验进度，不顺带学习技能或修改人物等级、JP。 |
| 解锁全部职业 | 按角色范围解锁全部适用职业，不受单个职业选择影响；已解锁项目保持原状。 |
| 设置 JP | 在“编辑 JP”输入 0～2147483647 的整数绝对余额；双方范围会分别设置相同数值。 |

主随从不能操作觉醒者专属职业；选择双方时，单项专属职业仅修改觉醒者，批量解锁将相关随从项列为跳过。JP 始终遵循角色选择。任何必要角色缺席时取消整个事务；资格位图无法核实时停用锁定。

## 确认、语言与字号

所有编辑按钮先生成预览。“当前保存尚未应用，请确认修改”表示尚未执行，点击绿色“确认修改”应用，或红色“放弃修改”撤销。改变角色、职业、等级、JP 输入、页面或语言会取消旧预览。

顶部“语言”可选自动、中文和 English。自动只读取游戏文字语言，中文对应中文界面，其他或未知语言对应英文。偏好保存在 `reframework/data/DD2SkillStateManager/settings.json`。职业、技能名和说明使用所选语言的游戏文本，Mod 不改变游戏文字或语音设置。

在 REFramework 设置中调整字体大小，随包字体会实时跟随；列宽、换行和窄面板预览随字号适配，无需独立字号设置。

## 编辑范围与保存

编辑范围为武器主动技能及所选职业 / JP 字段，不包括基础技能、被动能力、人物等级、任务和内容所有权。可以绕过职业等级、JP 购买和大师条件直接学习有效的指定技能；设置职业等级不会自动学习技能，不解锁未拥有的扩展内容。

**EX 技能继续由 DLC 武器词条提供。** EX 不参与普通等级选择和批量学习，武器和词条保持原生机制。

修改仅在确认按钮触发时执行，不持续覆盖正常游戏进度。操作由游戏正常保存机制持久化；卸载不会撤销已经保存的修改。

## 排错与恢复

目录未就绪时，先打开一次游戏的武器技能菜单，再使用“工具 → 刷新目录”。名称无法解析时显示枚举名或 ID。角色不可访问、数据只读、语言异常或操作失败时，使用“工具 → 导出诊断”。

数据位于 `reframework/data/DD2SkillStateManager/`：

| 文件 | 用途 |
| --- | --- |
| `settings.json` | 语言偏好 |
| `before_*.json` | 修改前快照 |
| `operation_*.json` | 操作结果 |
| `diagnostic_*.json` | 只读运行时诊断 |
| `writer-lock.json` | 恢复无法核验时的持久化修改锁 |

写入前必须保存并回读快照。事务失败时尝试恢复全部目标，再检查完整状态。若恢复失败，编辑会锁定：避免保存异常状态，恢复完整存档备份。

JSON 快照不是完整游戏存档，也不提供导入功能。需要完整恢复时退出游戏，将完整 `2054970` 备份恢复到原账号目录，并处理 Steam 云同步。确认存档已恢复且检查无误后，才移除 `writer-lock.json`。

分享诊断前检查是否包含私人路径或角色数据；反馈时说明游戏 / REFramework 版本、操作、角色范围、预期与实际结果。不要公开完整存档备份。

## 卸载

退出游戏，删除 `DD2SkillStateManager.lua`、同名模块文件夹及两份 `DD2SkillStateManager-CJK` 字体 / 许可证文件；Fluffy 用户可通过管理器停用。偏好与诊断可单独保留或删除本 Mod 的数据文件夹。只删除这些文件不会影响其他 Mod。
