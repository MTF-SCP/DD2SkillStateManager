# DD2 技能与职业管理 1.0

管理觉醒者与主随从的武器主动技能：单项学习、删除、设置真实等级，以及按职业或全部职业批量学习。技能自动读取游戏目录，ImGui 界面支持中文和英文。

**1.0 更新：修复职业 / JP 修改误回滚；新增一键解锁全部适用职业；当前状态与职业编辑分区；确认绿色、放弃 / 锁定红色，并突出待确认提示。** 支持中英文、角色范围选择及实时跟随 REFramework 字号。EX 继续由 DLC 武器词条提供。

适用于 PC Steam 版《Dragon's Dogma 2》，仅依赖 REFramework。调查环境：游戏 `4.0.0.0` / Steam 构建 `25290080`，REFramework `d1461375aee4ec3f313170f8eaad12064eb542d9` / TDB 83。

## 使用

1. 进入存档，等待角色载入。按 Insert，在 REFramework 的 `Script Generated UI` 展开“DD2 技能与职业管理”或“DD2 Skill Controller”。
2. 选择职业，可按技能名称或 ID 搜索，再选择技能。“当前状态”显示目标角色的获取状态和等级。觉醒者专属技能只显示觉醒者。
3. 选择目标等级，点击“学习 / 设置等级”，或点击“删除技能”。
4. 检查“确认修改”中的角色、状态变化和自动卸装数量；可展开查看具体职业和槽位，再点击绿色“确认修改”。黄色提示“当前保存尚未应用，请确认修改”表示还只是预览；红色“放弃修改”或更换选择会撤销预览。
5. 通过游戏正常保存。Mod 不主动存档。

## 职业与 JP

顶部“页面”选择“职业与 JP”。“当前状态”只读显示双方正在使用的职业、等级及 JP。“编辑所选职业”选择角色范围与职业，显示这个职业在双方的资格和等级，解锁 / 锁定 / 等级按钮放在此区。“编辑 JP”单独设置余额，沿用角色选择。默认目标觉醒者；全部操作先生成预览，再点绿色“确认修改”。技能页继续保持原来的双方同步规则。

- 职业资格：解锁仅给予资格，保留首次转职历史；首次转职仍按游戏规则收费。锁定保留经验、技能及装备配置。正在使用的职业须先转职，基础职业不强制锁定；位图无法唯一核实时锁定只读。
- 职业等级：选项来自游戏返回的最高等级。改变等级会设置游戏对应的累计职业经验；同级设置保留原经验进度。不会修改人物等级、消费/增加 JP 或顺带获取/遗忘技能和被动能力。
- “解锁全部职业”：按角色选择一次解锁全部适用职业，忽略单个职业选择。已解锁项目保持原状，主随从不能使用及未知归属的职业在预览中列为跳过项。双方操作需要双方均可访问，实际变更作为一个事务；不改变等级、JP、首次转职记录或技能。
- 专属职业：主随从不能操作；双方范围只修改觉醒者，预览明确列出实际角色。
- “编辑 JP”：是每个角色的一份可消费余额，不按职业分开。输入 0～2147483647 的整数，双方范围设置相同余额。JP 仍按角色选择，不受专属职业过滤。

需要主随从的操作在主随从缺席时整体取消；觉醒者单独操作不依赖主随从。输入、角色、职业、页面或语言变化会撤销旧预览。任何修改先写盘并核验完整快照；失败恢复原始职业经验及全部已修改目标，恢复失败则停用写入并要求完整存档恢复。职业数据只读时可导出诊断，具体错误留在报告中。

## 字号

在 REFramework 自身设置中调整默认字体大小，本 Mod 的中英文字体实时跟随，无需另设字号或重载。字体只加载一次；列宽、换行和预览依据当前字号测量，窄面板使用纵向预览。

## 语言

顶部“语言 / Language”提供自动、中文、English，默认自动。自动模式只读取游戏文字语言：简体/繁体中文对应中文界面，其他语言及未知语言统一显示英文。自动接口暂不可用时仍可手动选择；不会修改游戏语言或语音设置。

职业名、技能名和说明通过游戏 `get(Guid, via.Language)` 显式请求对应语言。中文显示采用简体中文文本；英文模式不会沿用游戏的日文、法文等其他语言文本。暂无法解析时显示枚举名或技能 ID，允许刷新。

手动选择立即写入 `reframework/data/DD2SkillStateManager/settings.json`，重启或重载后保留。切换语言会取消旧预览、清除名称搜索并重建文本缓存，保留选中技能 ID。翻译与有效等级核验分开，切换界面语言不会令原来不可获取的等级成为可获取等级。

“技能说明”“装备位置”按需展开；“批量学习”和“工具”默认折叠。批量预览每页显示 10 条角色技能状态，支持翻页；跳过原因与将卸下的槽位可以展开查看。首次选择技能时，目标等级优先采用觉醒者当前的有效等级。

目录暂未就绪时，打开一次职业公会武器技能菜单，在“工具”点击“刷新目录”。遇到错误可点“导出诊断”，文件在游戏目录 `reframework/data/DD2SkillStateManager/diagnostic_*.json`；完整错误另见 REFramework 日志。界面不显示内部方法签名、Lua 堆栈或文件路径。

## 修改与自动卸装规则

- 仅管理武器主动技能，不包括普通攻击、基础技能或被动能力。自动扫描游戏主动技能参数，不按连续 ID 猜测。
- 普通职业同步觉醒者和主随从；任何一方不可访问，整次请求取消。觉醒者专属职业只修改觉醒者。
- 可以直接学习指定技能，绕过职业阶级、JP 购买和大师获取条件。学习技能时不修改职业经验、JP、资格、任务及内容所有权；不会开放未拥有的扩展内容。
- 每项技能只提供它自身经过参数和本地化核验的等级。常规技能操作普通 Lv1/Lv2；单级技能只提供一个有效等级。不会将所有技能统一抬升到同一等级。
- **EX 由 DLC 武器词条给予，不属于编辑范围。** EX 不参与等级选择、批量授予或普通状态写入；武器及词条保持游戏原生机制。已拥有扩展中的新增普通主动技能按正常规则纳入。
- 获取状态通过原生记录属性和上下文 getter 交叉核验；不将“存在记录”视为已获取。删除保留预置记录，只重置所选技能到实际观察确认的未获取等级，不猜测等级零的含义。
- **删除或实际等级变更前，自动卸下目标角色所有职业槽中引用该技能的记录**，包括未使用职业和龙选者引用。双方全部待卸槽在预览中列出。确认后先完成卸装并核验，再修改学习状态；无需提前在游戏内卸下。
- 只清空预览指定的槽位，其他技能和槽位保持一致。操作后不自动重新装备，空槽由玩家按游戏正常流程安排。
- 相同等级且已获取属于无操作，保留装备。明确删除已未获取但仍被异常装备引用的技能时，也会清除对应槽位。
- “学习当前职业全部技能”覆盖所选职业完整目录；名称搜索不影响批量范围。“学习全部职业技能”覆盖全部目录。每项选自身最高可用等级；未知归属、内容不可用等项目明确跳过。装备中的可修改项目也会自动卸下。
- 批量学习保留已有更高原始等级，跳过该技能而不会降级；需要降级可单项明确设置。同步技能按双方一起跳过，其余项目作为同一个事务执行。
- 操作只由按钮触发，不持续干涉游戏中的学习和换装。预览后角色、学习记录、装备或目录变化会取消确认，需重新预览。

## 快照和失败恢复

实际修改前必须先成功保存并回读双方完整学习记录、全部装备槽和保护数据快照。文件位于 `reframework/data/DD2SkillStateManager/`：`before_*.json` 为修改前状态，`operation_*.json` 为结果日志。0.4.0 的 schema 5 包含职业/JP 操作类别、完整职业经验、人物等级与被动能力保护数据；诊断包含资格位图、实际接口和字体字号。空集合以 `{"__empty": true}` 保留。技术日志保留原始错误，不在 UI 显示堆栈。

修改及卸装使用同一个事务。卸装、学习写入或回读失败时，尝试恢复所有目标角色的学习记录、原始顺序和提示标记，然后通过游戏原生装备接口恢复槽位，再核验整体状态。恢复失败会暂停修改并导出诊断，持久化为 `writer-lock.json`。界面会显示必要的失败或恢复提示。

**操作快照不是完整游戏存档，不提供直接导回 JSON。** 完整恢复时退出游戏，将备份恢复到原 Steam 账号的完整 `2054970` 目录；有 Steam 云同步时先确保旧备份不会被云端覆盖。确认存档已恢复且游戏退出后，才可移除本 Mod 的 `writer-lock.json`。正常保存后的修改不会因卸载 Mod 自动撤销。

## 卸载

退出游戏，删除上述九个 Lua 文件及两份同名字体文件；只删除本 Mod 文件。Fluffy 安装者通过管理器停用卸载。诊断及操作快照可保留，或单独删除 `reframework/data/DD2SkillStateManager`。
